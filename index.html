Sobre mí

De la sala de cajeros al navegador

Llevo desde 2020 trabajando en campo: instalando, dando mantenimiento y resolviendo fallas en cajeros automáticos (Diebold, NCR) e infraestructura de red para clientes bancarios, educativos y de retail — siempre bajo acuerdos de nivel de servicio (SLA) exigentes y con alta disponibilidad como prioridad número uno.

En paralelo, estoy formándome como desarrollador web por mi cuenta: HTML, CSS y JavaScript puro, sin frameworks, escribiendo yo mismo la lógica de cada proyecto con guía paso a paso de Claude, mi asistente de IA para programar. Ya publiqué mi primer proyecto serio (una Pokédex que consume una API en tiempo real) en GitHub Pages.

Busco un rol donde ese doble perfil — operativo/infraestructura y desarrollo — sume: soporte técnico y redes con capacidad real de automatizar y construir herramientas internas.

github.com/MaxVF97/Pokedex
Pokédex Interactiva
Ver demo ↗

Aplicación de página única (pokedex_final.html) que consume la PokéAPI en tiempo real, escrita en JavaScript puro — sin frameworks — como parte de mi formación autodidacta. Escribí yo la lógica (peticiones a la API, manejo de estado, eventos del DOM) con guía paso a paso de Claude, mientras que el diseño visual grande se construyó junto con él, siempre con explicación de cada decisión de CSS.

  • Búsqueda por nombre/ID, modo aleatorio, tipos, debilidades y movimientos por nivel.
  • Modo de comparación de 2 Pokémon lado a lado, con selección interactiva de tarjetas.
  • Estadísticas base con barras de progreso y navegación anterior/siguiente.
  • Favoritos persistentes (localStorage) y sistema centralizado de audio.
  • Detección visual de Pokémon legendarios con efectos y tipografías propias.
  • Bugs resueltos documentados: anidación de bloques, estado obsoleto entre ciclos, timeouts sin cancelar.

github.com/MaxVF97/Lista-de-tareas
Lista de Tareas Interactiva
Ver demo ↗

Mi primer proyecto construido con Claude, y el punto de partida de mi formación autodidacta en desarrollo web: una aplicación para agregar, editar y completar tareas, escrita en HTML, CSS y JavaScript puro.

  • Agregar tareas con clic o tecla Enter, con validación de campo vacío.
  • Fecha y hora opcional por tarea, con checkbox que muestra/oculta el selector dinámicamente.
  • Edición de texto en línea (contentEditable) con salida automática al hacer clic fuera.
  • Ordenamiento automático — pendientes por fecha, completadas al final — animado con la técnica FLIP.
  • Delegación de eventos y atributos data-* para guardar información no visible.
  • Diseño oscuro y responsivo con CSS Grid, variables personalizadas e íconos SVG propios.
